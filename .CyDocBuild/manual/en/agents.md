1. Open the agent library from the rail. Create a profile: name, role, instructions, connector, model and assigned tools.
2. In the project Team section, create a team. Assign a manager, leads and members as needed; consultants provide specialist expertise.
3. Define responsibilities and hierarchy. Resolve the indicated issues, then mark the composition ready.
4. Open the member’s conversation or assign task cards on the board.

An assignment pins a profile revision. Editing the library creates a new revision without silently replacing existing assignments. Use revision preview/adoption to update deliberately. Local overrides belong to that assignment. Templates can reuse a team composition across projects.
