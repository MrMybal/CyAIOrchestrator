1. Start a model, engine, voice or tool download from its settings card. The catalogue selection alone does not download it.
2. Open Downloads to inspect queued/running jobs, received bytes, totals when known and errors.
3. Wait for completion and verification, then return to the feature to load or use the component.
4. If a download fails, inspect the specific job, destination, disk space and network before retrying.

On-demand components include the optional Claude Code native CLI and CyAnnota FFmpeg codec. CyTools portable packages are distinct from their own engines and model weights. A downloaded application may still need account setup, authentication or a running server. Settings read cached catalogues; checking a remote release is an explicit action.

```callout
{"type": "info", "title": "Keep in mind", "body": "Known totals and checksums depend on the official source. Do not treat an unknown size as zero or an installation acknowledgement as a completed download. Model/engine licences can differ from CyAI’s licence."}
```
