1. Use ＋ in the composer or supported paste/drop controls. Check the name and preview.
2. Send the attachment alone or with an instruction. Selected files belong to that conversation’s draft.
3. Click a supported image/video for an in-app preview. Enlarge or zoom images; use video playback controls.
4. Right-click the file or use its menu for File Explorer, external opening and copying a local link. Unsupported types can open with Windows.

Attachments keep their metadata and stored content. An unreadable format should not be mistaken for an absent file. Interpretation depends on the model’s modalities, connector and file tools. A local link is not a public URL another computer can download.

```callout
{"type": "info", "title": "Keep in mind", "body": "If a preview reports a path outside the conversation’s folders, check its actual location and registered working folders. Attach/import the file or register the intended folder. A broken preview is not proof of delivery to an AI."}
```
