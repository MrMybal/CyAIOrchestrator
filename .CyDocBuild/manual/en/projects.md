1. Click ＋ in the rail, choose the folder and name the project. Add a colour or icon if useful.
2. Open its assistant to describe an existing project or prepare instructions, memory and team.
3. Create conversations by workstream. Organize categories, favourites and archives from their menus.

| Location | Contents |
| --- | --- |
| Project | Conversations, shared memory, instructions, team, board, media, spaces and enabled plugins. |
| Direct message | Independent conversation with its own workspace and attachments; no inherited project memory or plugin bindings. |
| Project folder | Real working files. These are separate from the SQLite conversation history. |

```callout
{"type": "info", "title": "Keep in mind", "body": "Registering a folder does not automatically send all its files to every model. The context selection, tool access and provider’s own session determine what the agent receives."}
```
