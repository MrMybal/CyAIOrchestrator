| Action | Default control |
| --- | --- |
| Send message | Enter, when Enter-to-send is enabled. |
| New line | Shift+Enter. |
| File actions | Right-click a file or use its accessible menu. |
| 3D camera | Drag: orbit. Wheel: zoom. Right-drag: pan. |
| Close a preview | Its close control or Escape. Escape also leaves global settings/library when no dialog is open. Close the documentation window with its native window control. |
| Guide images | Use Enlarge in window; − / ＋ zoom, Reset view recenters, Escape leaves enlargement. Focus the image for keyboard + / − / 0 and arrow controls; touch supports pan and pinch. |
| Guide navigation | F1 opens help for the current CyAI panel. Ctrl+K searches the documentation. Tab/Enter activate links; the header language selector keeps common page/section IDs. Navigation restores reading positions during the reader session. |
| Print a guide chapter | Use the browser/system print command where available; the print stylesheet focuses on the current article. |

| Term | Meaning |
| --- | --- |
| Connector | Adapter connecting CyAI to a provider, native CLI or local engine. |
| Model | The exact inference model/variant selected through that connector. |
| Profile / assignment | Reusable agent definition / revision pinned to a project team. |
| Mission / step | Recorded execution / one part of its configured plan. |
| Task / report / acceptance | Work card / submitted evidence / explicit review decision. |
| Context / shared memory | Information provided for a request / stable project entries selected for reuse. |
| Plugin / CyTool / MCP | Integration / standalone tool application / protocol exposing operations and resources. |
| Job identifier | A reference used to follow asynchronous work, not proof of completion. |
| GGUF / PBR | Local model file format / physically based material rendering. |
