| Category | Controls |
| --- | --- |
| Models & preferences | Personal model ratings, provider catalogues and orchestration preferences. |
| Appearance | English/French language, themes and visual preferences. |
| Connectors / MCP / Plugins / CyTools | Provider and integration setup, separate from local inference models. |
| Folders / Backup | Data storage, backup destinations and migration options. |
| Context & AI | Conversation/context preferences, including Enter-to-send behaviour. |
| Windows application | Desktop integration and lifecycle preferences. |

1. Open Appearance and choose English or Français, then save. English is the default for unsupported/missing preferences.
2. Language changes reload the interface while preserving drafts; background service work continues. This guide and bundled editors follow the selected language.
3. For a storage change, use the folder settings and follow the restart instructions. Do not manually move a database while its service is using it.
