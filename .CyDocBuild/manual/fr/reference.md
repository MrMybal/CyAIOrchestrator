| Action | Commande par défaut |
| --- | --- |
| Envoyer | Entrée si l’envoi par Entrée est activé. |
| Nouvelle ligne | Maj+Entrée. |
| Actions de fichier | Clic droit ou menu accessible. |
| Caméra 3D | Glisser : rotation. Molette : zoom. Clic droit glissé : déplacement. |
| Fermer un aperçu | Bouton fermer ou Échap. Échap quitte aussi paramètres/bibliothèque sans dialogue ouvert. Fermez la documentation avec la commande native de sa fenêtre. |
| Images du guide | Utilisez Agrandir dans la fenêtre ; − / ＋ zooment, Recentrer réinitialise, Échap quitte l’agrandissement. L’image ciblée accepte + / − / 0 et les flèches ; au toucher : déplacement et pincement. |
| Navigation du guide | F1 ouvre l’aide du panneau CyAI courant. Ctrl+K recherche dans la documentation. Tab/Entrée activent les liens ; le sélecteur de langue conserve les identifiants communs. La navigation restaure les positions de lecture pendant la session. |
| Impression | Commande d’impression navigateur/système si disponible ; la feuille d’impression cible le chapitre courant. |

| Terme | Sens |
| --- | --- |
| Connecteur | Adaptateur vers fournisseur, CLI natif ou moteur local. |
| Modèle | Modèle/variante exact choisi via ce connecteur. |
| Profil / affectation | Définition réutilisable / révision figée dans une équipe. |
| Mission / étape | Exécution enregistrée / partie de son plan. |
| Tâche / rapport / acceptation | Carte de travail / preuves rendues / décision explicite de revue. |
| Contexte / mémoire commune | Informations d’une demande / éléments stables réutilisables. |
| Plugin / CyTool / MCP | Intégration / application outil / protocole d’opérations et ressources. |
| Identifiant de job | Référence de suivi d’un travail asynchrone, pas preuve de fin. |
| GGUF / PBR | Format de modèle local / rendu de matériaux physiquement basé. |
