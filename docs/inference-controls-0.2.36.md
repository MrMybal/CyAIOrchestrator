# CyAI 0.2.36 — arrêt, saisie et compteurs locaux

- Bouton ■ Arrêter dans la zone de saisie pendant une réponse, en complément de la barre de suivi. Annule la mission courante. Pour CyAI local, un observateur d’annulation arrête le processus llama-server même si la requête HTTP attend encore le calcul du prompt. Le moteur local est déchargé ; son prochain usage le rechargera. Le résultat partiel et les événements restent enregistrés par le mécanisme existant.
- Arrêter/décharger dans les paramètres et le raccourci global peut aussi annuler l’inférence locale active. Il s’agit du moteur partagé par les conversations : l’action globale interrompt donc son utilisateur courant.
- Entrée envoie par défaut, Maj+Entrée fait un saut de ligne. Composition IME et répétition de touche ne déclenchent pas d’envoi. Ctrl/Cmd+Entrée reste disponible. Préférence persistante dans Paramètres → Contexte & IA → Envoi des messages pour revenir à Ctrl+Entrée.
- Les compteurs OpenAI/llama.cpp prompt_tokens/completion_tokens sont normalisés en input_tokens/output_tokens. Les tours successifs d’appels d’outils sont cumulés, sans compter deux fois les mises à jour d’un même tour. Les statistiques reconnaissent aussi les anciens événements conservés. Les tokens locaux figurent dans le suivi de la conversation lorsqu’ils sont transmis par le moteur. Pas d’estimation présentée comme une mesure : une annulation avant les compteurs finaux peut ne pas fournir de décompte. Les tokens de sortie peuvent inclure le raisonnement du modèle.
- VRAM : Windows WDDM GPU Process Memory/DedicatedUsage par processus, regroupé pour CyAI et ses enfants. Le moteur local a son propre compteur. Secours NVIDIA quand nécessaire. GPU total est distinct, car il inclut les autres applications. Mesure en arrière-plan ; n/d reste affiché si elle est indisponible.

## Vérifications
458 tests, 2 ignorés, sans échec. Tests spécifiques : annulation d’un HTTP bloqué avant le premier token, déchargement pendant une génération, normalisation tokens et regroupement des compteurs Windows. Contrôle de syntaxe JavaScript.
Essai réel isolé sur RTX 3090 et Bonsai 2 / PrismML : réponse Bonjour ; 58 tokens d’entrée et 183 de sortie déclarés par le moteur. VRAM dédiée du moteur 6 550 401 024 octets (6,10 Gio). Annulation pendant le traitement d’un long prompt : 0,625 seconde, résultat Cancelled, processus arrêté et modèle déchargé. Ce délai est celui de cet essai, pas une garantie universelle.
Validation navigateur avec faux connecteur sans appel externe : Maj+Entrée conserve deux lignes et zéro message envoyé ; Entrée crée un unique message avec les deux lignes ; bouton ■ Arrêter visible et utilisable.
Reproduire : experiments/voice-engines/inference-probe-036.py et run-tests-036.py. Journaux correspondants dans le même dossier. L’application utilisateur n’a pas été redémarrée.
