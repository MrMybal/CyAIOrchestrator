# CyAI Orchestrator 0.2.62

The CyTools catalogue now follows the official GitHub repositories: AudioStudio, AudioLibrary, AIChat, PersonaRP, Storyboard and MeshStudio. Users can check releases, download verified Windows portable packages and connect their MCP servers, or add an installed folder. Download progress and failures appear in settings and Downloads. Engines and model weights remain separate user downloads.

CyAICodex now exposes the current skill and image tools. CyTask has a bundled MCP bridge and server/token settings. Existing project bindings and disabled states survive tool updates; previous integrations remain available in a collapsed compatibility section.

The embedded editors are updated to CyAnnota 0.4.4 and CyMD 0.1.4, with corresponding sources and licences. CyAnnota follows the selected interface language.
