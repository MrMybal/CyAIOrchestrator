1. Open a conversation and choose connector/model. Describe the result and attach relevant files.
2. By default Enter sends and Shift+Enter adds a line. Attachments can be sent without text.
3. During a response, add a follow-up to the queue. Send now interrupts the current response to send that message immediately.
4. Stop cancels active work. Review the output and changed files before retrying.

Drafts and selected attachments follow their own conversation within the window session. Text typed after a send remains in the composer when the send is acknowledged. Message actions let you quote, copy, read aloud, propose memory or branch the history. Rename, export and archive are in the conversation toolbar.

```callout
{"type": "info", "title": "Keep in mind", "body": "Branching copies history up to a message. It does not restore project files or undo earlier commands. Stop, rename and archive do not reverse existing file changes either."}
```
