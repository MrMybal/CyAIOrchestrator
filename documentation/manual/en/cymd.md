1. Enable CyMD and open its editor from the conversation toolbar or a compatible attachment.
2. Write/edit Markdown with its editing and preview controls. It follows the English/French interface preference.
3. Save to CyAI and wait for confirmation. A new attachment is created; the original is preserved.
4. Review the saved document, then send it if needed for the next request.

The embedded editor is different from a Windows file association. Open externally uses the application associated with the extension. Saving to a conversation does not automatically overwrite an unrelated file in the project folder.
