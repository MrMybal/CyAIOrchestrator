1. Use ＋ in Spaces to create a named whiteboard.
2. Add notes, choose colours and move them by their grip. Drag a link handle to another note to connect them.
3. Pan or zoom the canvas, edit note text and wait for Saved.
4. If another window or agent changes the board, reload when a conflict is reported.

Whiteboards save automatically with version checks to avoid silently overwriting concurrent changes. Notes and arrows organize ideas; they do not execute a mission. Use orchestration or the task board for dependencies that must control execution.
