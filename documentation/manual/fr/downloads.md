1. Lancez le téléchargement depuis la fiche du modèle, moteur, voix ou outil. Une sélection seule ne télécharge rien.
2. Ouvrez Téléchargements pour voir files, progression, octets, total disponible et erreurs.
3. Attendez fin et vérification, puis revenez à la fonctionnalité pour utiliser le composant.
4. En cas d’échec, vérifiez job, destination, espace disque et réseau avant reprise.

Les composants à la demande incluent le CLI Claude Code et le codec FFmpeg CyAnnota. Les paquets CyTools sont distincts de leurs moteurs et poids. Une application téléchargée peut demander compte, authentification ou serveur actif. Les réglages lisent les catalogues en cache ; vérifier une release distante est une action explicite.
