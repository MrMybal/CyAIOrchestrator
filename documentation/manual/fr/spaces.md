1. Utilisez ＋ dans Espaces pour créer un tableau nommé.
2. Ajoutez des notes, choisissez couleurs et positions avec les poignées. Tirez un connecteur vers une autre note pour les relier.
3. Déplacez ou zoomez le canevas, modifiez le texte et attendez Enregistré.
4. Si une fenêtre ou un agent modifie le tableau, rechargez lorsqu’un conflit est signalé.

Les tableaux s’enregistrent automatiquement avec contrôle de version pour éviter l’écrasement de modifications concurrentes. Notes et flèches organisent les idées, sans exécuter de mission. Utilisez orchestration ou board pour les dépendances exécutables.
